#  📟 Digital Logic Design Learning & Circuit Projects
> Designed by Vu Dai Duong - CE student at UIT

## Overview
This repository serves as a comprehensive portfolio of digital logic circuit designs and architectural optimizations. Developed as part of the **CE118 - Digital Logic Design** course,
these projects demonstrate the transition from theoretical Boolean logic to functional hardware components like ALUs, Memory units, and Finite State Machines.

## Tools Used
* **Quartus:** For schematic design, VHDL model and waveform simulation.
* **Draw-io:** For designing FSM state diagrams and architectural overviews.
